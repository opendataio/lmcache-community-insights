Metric Notes

PR backlog is reconstructed from PR creation and close timestamps. Stars and forks use currently existing GitHub objects, so removed stars and deleted forks are not visible in the public API history. Some fork records can be counted by GitHub's repository summary without being available in the timestamped fork connection. The contributor curve is based on default-branch commit authors first seen in commit history.
